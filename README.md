# Universal POS

- `client/`  the website (plain HTML/CSS/JS). Responsive: phones, tablets and desktop. Open `client/index.html` through a local server.
- `server/`  the backend (Phases 1 and 2 written, see `server/README.md`).

Run the website only:  `npx serve client`  (or `python -m http.server 8080 --directory client`).
Staff logins: manager@shop.co.ke / manager123, cashier@shop.co.ke / cashier123. Clients create their own account.
